## filteratlas.xs.evaluate

Cross sections, attenuation and figures of merit (definitions fixed before the computation).

- `LAM`: wavelength grid of the thermal band (0.5-3 Å, 200 points)
- `LAM_HOT`: wavelength grid of the hot band (0.3-1.0 Å)
- `LAM_WIDE`: wide grid of the stored curves (0.3-4.5 Å, 421 points)

### `evaluate(cfg, temps)`

All per-material thermal quantities of the atlas, for each temperature: full model and composition-only proxy.

**Parameters.**
- cfg: NCrystal configuration string or registered material name.
- temps: temperatures in K; a temperature above 100 K is labelled 293K, otherwise 77K.

**Returns.** dict with mu_1.0_<tag>, mu_1.8_<tag> (1/cm), proxy_1.0_<tag>, proxy_1.8_<tag>, L08_<tag>, L08_proxy_<tag>, L08_hot_<tag>, L08_hot_proxy_<tag> (cm) and numberdensity_A3 (atoms/Å³).

```python
from filteratlas.xs.evaluate import evaluate
evaluate("stdlib::Al2O3_sg167_Corundum.ncmat", (293.15, 77.0))["L08_77K"]
```

### `mu_offbragg(cfg, T, wl)`

Off-Bragg single-crystal attenuation coefficient: inelastic plus incoherent elastic scattering plus absorption. Coherent elastic (Bragg) scattering is left out, as for a large crystal oriented away from Bragg reflections.

**Parameters.**
- cfg: NCrystal configuration string or registered material name (without the temperature).
- T: crystal temperature in K.
- wl: wavelengths in Å (scalar or array).

**Returns.** (mu, info): mu in 1/cm at the wavelengths, and the NCrystal Info object.

```python
from filteratlas.xs.evaluate import mu_offbragg
mu, info = mu_offbragg("stdlib::Al2O3_sg167_Corundum.ncmat", 293.15, [1.0, 1.8])
```

### `mu_proxy(info, wl)`

Composition-only attenuation: n * sum_i x_i (sigma_abs,i(lambda) + sigma_inc,i), free elements, no phonons.

**Parameters.**
- info: NCrystal Info object (from mu_offbragg), which gives the composition and the atom density.
- wl: wavelengths in Å (scalar or array).

**Returns.** mu in 1/cm at the wavelengths.

```python
from filteratlas.xs.evaluate import mu_offbragg, mu_proxy
mu_proxy(mu_offbragg("stdlib::Al2O3_sg167_Corundum.ncmat", 293.15, 1.8)[1], [1.0, 1.8])
```

### `t_band(mu, L, lam=LAM)`

Transmission of a slab of thickness L averaged over the thermal band with Maxwellian weights.

**Parameters.**
- mu: attenuation in 1/cm on the wavelength grid lam.
- L: thickness in cm.
- lam: wavelength grid in Å (default `LAM`, the thermal band 0.5-3 Å).

**Returns.** transmission between 0 and 1.

```python
from filteratlas.xs.evaluate import LAM, mu_offbragg, t_band
t_band(mu_offbragg("stdlib::Al2O3_sg167_Corundum.ncmat", 293.15, LAM)[0], 5.0)
```

### `l_target(mu, lam=LAM, target=T_TARGET)`

Thickness at which the band transmission equals the target (L0.8 for the default target 0.80).

**Parameters.**
- mu: attenuation in 1/cm on the grid lam.
- lam: wavelength grid in Å (default `LAM`).
- target: transmission (default `T_target`, 0.80).

**Returns.** thickness in cm (Brent root); inf if the attenuation is zero or too small.

```python
from filteratlas.xs.evaluate import LAM, l_target, mu_offbragg
l_target(mu_offbragg("stdlib::Si_sg227.ncmat", 293.15, LAM)[0])
```

### `maxwellian_flux(lam, lam_t=LAMBDA_T)`

Maxwellian flux per unit wavelength, phi(lambda) ~ lambda^-5 exp(-lambda_T^2 / lambda^2), unnormalised.

**Parameters.**
- lam: wavelengths in Å (array).
- lam_t: characteristic wavelength in Å (default: `lambda_T_A` of `configs/figures_of_merit.yaml`, 300 K).

**Returns.** array of weights, same shape as lam.

```python
from filteratlas.xs.evaluate import LAM, maxwellian_flux
maxwellian_flux(LAM).argmax()
```

### `lambda_T(T=300.0)`

Characteristic wavelength of a Maxwellian of temperature T, h / sqrt(2 m_n k_B T).

**Parameters.**
- T: temperature in K (default 300).

**Returns.** wavelength in Å.

```python
from filteratlas.xs.evaluate import lambda_T
round(lambda_T(300.0), 4)
```

### `curves(cfg, T)`

Full-model and composition-only attenuation on the wide wavelength grid `LAM_WIDE` (0.3-4.5 Å). Used to recompute L0.8 for another band or moderator temperature without rerunning NCrystal (see l_target_band).

**Parameters.**
- cfg: NCrystal configuration string or registered material name.
- T: crystal temperature in K.

**Returns.** (mu_full, mu_proxy): two lists of float32 values in 1/cm on `LAM_WIDE`.

```python
from filteratlas.xs.evaluate import curves
mu_full, mu_proxy = curves("stdlib::Al2O3_sg167_Corundum.ncmat", 293.15)
```

### `l_target_band(mu_wide, band, lam_t=LAMBDA_T, n=N_LAMBDA)`

L0.8 for any band and moderator temperature, from a curve stored on `LAM_WIDE`.

**Parameters.**
- mu_wide: attenuation in 1/cm on `LAM_WIDE` (from curves).
- band: (lowest, highest) wavelength in Å, inside 0.3-4.5 Å.
- lam_t: characteristic wavelength of the moderator in Å (lambda_T(T_moderator)).
- n: grid points in the band.

**Returns.** thickness in cm at which the band transmission is T_target (0.80); inf if the attenuation is too small.

```python
from filteratlas.xs.evaluate import curves, l_target_band, lambda_T
l_target_band(curves("stdlib::Al2O3_sg167_Corundum.ncmat", 293.15)[0], (0.5, 4.5), lambda_T(40.0))
```

## filteratlas.fom.rejection

Uncollided fast-neutron and gamma rejection, from the elemental ENDF/B-VIII.0 tables written by filteratlas.ingest.nucdata (data/intermediate/nucdata/endfb80_elements.npz).

### `sigma_tot(formula)`

Mean free-atom total neutron cross section per atom of a formula on the ENDF/B-VIII.0 energy grid.

**Parameters.**
- formula: chemical formula.

**Returns.** array in barn on tables()["E"].

```python
from filteratlas.fom.rejection import sigma_tot
sig = sigma_tot("Al2O3")
```

### `a_fast(sig, n, L, spectrum)`

Uncollided fast-neutron rejection, −ln of the spectrum-averaged transmission of a slab. A_fast(L) = −ln[ ∫ S(E) exp(−n σ_tot(E) L) dE / ∫ S(E) dE ].

**Parameters.**
- sig: per-atom total cross section in barn on the grid (from sigma_tot).
- n: atom number density in atoms/Å³.
- L: thickness in cm (scalar or array).
- spectrum: "1E" (1/E over 1 eV-100 keV) or "watt" (fission spectrum over 100 keV-10 MeV).

**Returns.** array of rejections, one per thickness.

```python
from filteratlas.fom.rejection import a_fast, sigma_tot
a_fast(sigma_tot("Al2O3"), 0.1174, [5.0, 10.0], "1E")
```

### `mu_gamma(formula, n)`

Narrow-beam photon attenuation coefficients at 1 MeV and 6 MeV (coherent scattering included).

**Parameters.**
- formula: chemical formula.
- n: atom number density in atoms/Å³.

**Returns.** (mu at 1 MeV, mu at 6 MeV) in 1/cm; the photon rejection at thickness L is mu * L.

```python
from filteratlas.fom.rejection import mu_gamma
mu_gamma("Al2O3", 0.1174)
```

### `mu_epi(formula, n)`

Free-atom total neutron attenuation coefficient at 1 eV (the numerator of the Nieman-type ratio).

**Parameters.**
- formula: chemical formula.
- n: atom number density in atoms/Å³.

**Returns.** attenuation in 1/cm.

```python
from filteratlas.fom.rejection import mu_epi
mu_epi("Al2O3", 0.1174)
```

### `fractions(formula)`

Atomic fractions of a formula.

**Parameters.**
- formula: chemical formula, e.g. "Al2O3".

**Returns.** dict {element: fraction}, summing to 1.

```python
from filteratlas.fom.rejection import fractions
fractions("Al2O3")
```

### `tables()`

Elemental ENDF/B-VIII.0 tables and spectrum weights, loaded once from data/intermediate/nucdata.

**Returns.** dict with the energy grid "E" (eV), total cross sections "sig" (barn), photon cross sections "phsig", the element indices "el" and "ph", and the trapezoid weights of the two neutron spectra under "spectra".

```python
from filteratlas.fom.rejection import tables
len(tables()["E"])
```
