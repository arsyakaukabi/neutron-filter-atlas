# Python interface: materials from phonons

What this page is for: computing a phonon density of states with a learned potential (or any ASE calculator, or given force constants), building NCrystal materials from it or from a Debye temperature, and the stability and mean-energy helpers.
Who should read it: users who compute their own crystals from Python.

Generated by `tools/docs/gen_api.py` from the docstrings; edit the docstrings, not this page. Conventions, units and
the split between public and internal modules are on the first page, [Python interface](api.md). Examples that use
`dos` assume `dos = load_dos("data/upstream/mp/phonon_dos/pheasy/aaaegyio.json.gz")` (sapphire).

Contents: [`dynamics.mlip_run`](#filteratlasdynamicsmlip_run), [`xs.ncmat`](#filteratlasxsncmat), [`xs.mp_models`](#filteratlasxsmp_models)

## filteratlas.dynamics.mlip_run

MLIP phonons for the benchmark set (protocol fixed before the computation). No NCrystal needed. Environments: MACE-MP-0 and ORB v3 in requirements-mlip-benchmark.txt (e3nn 0.4.4, required by the pickled MACE-MP-0 model); SevenNet in requirements-mlip.txt (sevenn pulls e3nn 0.6.0).

### `calculator(name, device='cpu')`

ASE calculator of a learned interatomic potential, as used for the benchmark and the atlas. Needs the matching learned-potential environment (requirements-mlip*.txt).

**Parameters.**
- name: "sevennet_mf_ompa" (the atlas model), "mace_mp0_medium" or "orb_v3_cons_inf_omat".
- device: "cpu" or "cuda".

**Returns.** (calculator, precision): the ASE calculator and a text naming its floating-point precision.

**Raises.** ValueError for an unknown name.

```python
from filteratlas.dynamics.mlip_run import calculator
calc, precision = calculator("sevennet_mf_ompa")   # in the SevenNet environment
```

### `relax(atoms, calc, steps=None)`

Relax positions and cell with the space-group symmetry fixed (FIRE, FrechetCellFilter, fmax 0.005 eV/Å).

**Parameters.**
- atoms: ase.Atoms to relax (not modified; a relaxed copy is returned).
- calc: any ASE calculator (a learned potential from calculator(), or another).
- steps: largest number of FIRE steps (None = relax_max_steps of configs/mlip.yaml, 500).

**Returns.** (atoms, converged, steps_taken, largest_force_eV_per_A).

```python
from ase.build import bulk; from ase.calculators.emt import EMT; from filteratlas.dynamics.mlip_run import relax
relaxed, converged, steps, fmax = relax(bulk("Al", "fcc", a=4.1), EMT())
```

### `phonons(syms, lat, frac, sc, prim, calc=None, fc=None)`

Phonon DOS of a crystal by finite displacements (phonopy), in the file format of the pipeline. Either computes forces on displaced supercells (0.01 Å) with calc, or uses given force constants fc. Then symmetrises the force constants, finds the lowest frequency on a 40 Å Gamma-centred mesh and at the supercell-commensurate q-points, and computes the site-projected DOS (tetrahedron method).

**Parameters.**
- syms: chemical symbols of the unit cell, one per atom.
- lat: 3x3 lattice vectors in Å (rows).
- frac: fractional coordinates, one row per atom.
- sc: 3x3 supercell matrix (the atlas uses a diagonal supercell of at least 12 Å per axis).
- prim: 3x3 primitive matrix (numpy.eye(3) if the cell is primitive).
- calc: ASE calculator for the forces (ignored if fc is given).
- fc: optional phonopy force constants of that supercell.

**Returns.** (dos, min_freq_mesh_THz, min_freq_commensurate_THz, n_displacements); dos is a dict with "frequencies", "densities", "projected_densities" and "structure", ready for filteratlas.xs.ncmat.build_vdos_material.

```python
import numpy as np; from ase.build import bulk; from ase.calculators.emt import EMT; from filteratlas.dynamics.mlip_run import phonons
dos, fmesh, fcomm, nd = phonons(["Al"], bulk("Al", "fcc", a=4.05).cell[:], [[0, 0, 0]], np.diag([4, 4, 4]), np.eye(3), calc=EMT())
```

## filteratlas.xs.ncmat

Build NCrystal materials from MP structures with per-element VDOS.

### `element_vdos(dos, floor_meV=None)`

Per-element vibrational DOS from the site-projected phonon DOS, on an energy grid in eV. Bins below the floor are dropped and NCrystal extrapolates g(E) ~ E^2 below the first kept point (the DOS near zero frequency carries a smearing tail of the acoustic modes).

**Parameters.**
- dos: phonon DOS dict with "frequencies" (THz), "projected_densities" (one row per site) and "structure".
- floor_meV: lowest energy kept in meV (None = `vdos_floor_meV` of `configs/vdos.yaml`, 2 meV).

**Returns.** dict {element: (energy grid in eV, density)}.

**Raises.** ValueError if the projected DOS does not match the structure or an element has no positive-frequency DOS.

```python
from filteratlas.xs.ncmat import element_vdos
sorted(element_vdos(dos))
```

### `stability(dos)`

DOS rule for dynamical stability: the fraction of the DOS weight below `unstable_freq_THz` (−0.5 THz).

**Parameters.**
- dos: phonon DOS dict with "frequencies" (THz) and "densities".

**Returns.** (weight, stable): the unstable fraction and whether it is at most `unstable_weight_max` (0.5 %).

```python
from filteratlas.xs.ncmat import stability
stability(dos)
```

### `build_vdos_material(dos, name, floor_meV=None, vdos=None)`

Register an in-memory NCrystal material from a structure and per-element vibrational DOS.

**Parameters.**
- dos: phonon DOS dict with "structure" (and "frequencies", "projected_densities" unless vdos is given).
- name: name for the material; ".ncmat" is appended.
- floor_meV: VDOS floor in meV (None = 2 meV).
- vdos: optional precomputed {element: (energy grid in eV, density)}; otherwise taken from the DOS.

**Returns.** the registered material name, usable wherever NCrystal takes a configuration string.

**Raises.** RuntimeError if NCrystal would fall back to a Debye model for any atom.

```python
from filteratlas.xs.ncmat import build_vdos_material
name = build_vdos_material(dos, "my_crystal")   # then filteratlas.xs.evaluate.evaluate(name, (293.15, 77.0))
```

### `build_debye_material(structure, theta_d, name)`

Register an NCrystal material in which every atom has the same Debye temperature.

**Parameters.**
- structure: pymatgen Structure or its dict.
- theta_d: Debye temperature in K.
- name: name for the material; ".ncmat" is appended.

**Returns.** the registered material name.

```python
from filteratlas.xs.ncmat import build_debye_material
name = build_debye_material(dos["structure"], 1000.0, "my_debye")
```

### `debye_temperature(K_gpa, G_gpa, density_gcc, nsites, volume_A3)`

Debye temperature from the Voigt-Reuss-Hill moduli (Anderson 1963).

**Parameters.**
- K_gpa: bulk modulus in GPa.
- G_gpa: shear modulus in GPa.
- density_gcc: mass density in g/cm³.
- nsites: atoms in the cell.
- volume_A3: cell volume in Å³.

**Returns.** Debye temperature in K, or nan if a modulus is missing or not positive.

```python
from filteratlas.xs.ncmat import debye_temperature
debye_temperature(165.0, 66.0, 2.33, 8, 160.2)   # silicon
```

### `composer(structure)`

NCrystal NCMATComposer for a structure, and the map from its atom labels to elements.

**Parameters.**
- structure: pymatgen Structure or its dict.

**Returns.** (composer, labels): the NCMATComposer and a dict {label: element symbol}.

```python
from filteratlas.xs.ncmat import composer
c, labels = composer(dos["structure"])
```

### `to_ase(structure)`

ASE Atoms from a pymatgen Structure (or its dict), keeping only species, positions and cell.

**Parameters.**
- structure: pymatgen Structure or Structure.as_dict().

**Returns.** ase.Atoms with periodic boundary conditions.

```python
from filteratlas.xs.ncmat import to_ase
to_ase(dos["structure"]).get_chemical_formula()   # dos from filteratlas.ingest.mp.load_dos
```

## filteratlas.xs.mp_models

MP-phonon models for the triviality test: full model vs elemental proxy vs Debye-from-elastic, per compound.

### `mean_phonon(dos)`

Mean phonon energy of a DOS (first moment over positive frequencies).

**Parameters.**
- dos: phonon DOS dict with "frequencies" (THz) and "densities".

**Returns.** mean energy in meV, or nan if the DOS has no positive-frequency weight.

```python
from filteratlas.xs.mp_models import mean_phonon
mean_phonon(dos)
```
