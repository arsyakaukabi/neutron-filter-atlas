# Python interface

What this page is for: the public Python functions of the package `filteratlas`, with signature, purpose,
parameters, return value and an example. This page covers configuration, data paths, the step runner, reading phonon
files and Pareto fronts; [materials from phonons](api-materials.md) and
[cross sections and figures of merit](api-cross-sections.md) continue it.
Who should read it: users who compute their own crystals or read the atlas from Python.

Generated by `tools/docs/gen_api.py` from the docstrings; edit the docstrings, not this page. Install the package
first (`pip install -e .`, see [Installation](installation.md)). The examples run from the repository root with the
released data in place; an example that uses `dos` assumes
`dos = load_dos("data/upstream/mp/phonon_dos/pheasy/aaaegyio.json.gz")` (sapphire).

**Public and internal.** The modules and functions on this page and the two pages that continue it are the public
interface. Everything else in
`filteratlas` is internal: the modules that implement a pipeline step (a `main()` called from `pipelines/NN_*.py`)
and their helpers. Internal code is documented by its docstrings and may change between versions. Two internal
modules read data when they are imported, so import them only with the data in place:
`filteratlas.atlas.assemble` and `filteratlas.fom.rejection` (the latter loads the nuclear-data table on first use).

Units throughout: wavelength in Å, energy in eV unless a name says meV, attenuation in 1/cm, cross sections in
barn, thickness in cm, atom number density in atoms/Å³ (so that n[Å⁻³] × σ[b] = μ[cm⁻¹]).

Contents: [`common.config`](#filteratlascommonconfig), [`common.paths`](#filteratlascommonpaths), [`common.hashing`](#filteratlascommonhashing), [`common.pipeline`](#filteratlascommonpipeline), [`ingest.mp`](#filteratlasingestmp), [`atlas.fronts`](#filteratlasatlasfronts)

## filteratlas.common.config

Load the YAML configuration in `configs/`.

### `cfg(name)`

Parsed `configs/<name>.yaml`, cached. Values are returned exactly as written in the file (lists stay lists); numbers such as 1e5 are read as floats.

**Parameters.**
- name: file name without extension, e.g. "figures_of_merit".

**Returns.** dict with the content of the file.

```python
from filteratlas.common.config import cfg
cfg("figures_of_merit")["band_A"]
```

### `tup(x)`

Convert YAML lists to tuples, recursively.

**Parameters.**
- x: any value read from a configuration file.

**Returns.** the same value with every list replaced by a tuple.

```python
from filteratlas.common.config import tup
tup([[0.5, 3.0], 1])
```

## filteratlas.common.paths

Every data path used by the code, resolved from `configs/paths.yaml`.

### `D(key)`

Path of a data directory registered in `configs/paths.yaml` (created if absent).

**Parameters.**
- key: directory key under `dirs` in `configs/paths.yaml`, e.g. "mp" or "nucdata".

**Returns.** pathlib.Path under the data root (`data/`, or `FA_DATA` if set).

```python
from filteratlas.common.paths import D
D("mp")
```

### `F(name)`

Path of a data file registered in `configs/paths.yaml` (its parent directory is created if absent).

**Parameters.**
- name: file name under `files` in `configs/paths.yaml`, e.g. "atlas.parquet".

**Returns.** pathlib.Path under the data root (`data/`, or `FA_DATA` if set).

**Raises.** KeyError if the name is not registered.

```python
from filteratlas.common.paths import F
F("atlas.parquet")
```

### `env_file()`

Path of the `.env` file with API keys (`FA_ENV` overrides; the file is never tracked in git).

**Returns.** pathlib.Path, by default `.env` in the repository root.

```python
from filteratlas.common.paths import env_file
env_file().name
```

## filteratlas.common.hashing

SHA-256 of files (data manifest, frozen-input checks).

### `sha256(path)`

SHA-256 checksum of a file, as used in `data/MANIFEST.csv`.

**Parameters.**
- path: file path.

**Returns.** hexadecimal digest (str).

```python
from filteratlas.common.hashing import sha256
sha256("data/MANIFEST.csv")[:12]
```

## filteratlas.common.pipeline

Tiny step runner shared by the pipelines/ entry points.

### `Step(name, fn, env='main', note='', kwargs=field(default_factory=dict))`

One sub-step of a pipeline script: its name, the function it runs, the environment it needs ("main", "openmc", "mlip", "network" or "archive"), the one-line description shown by --list, and keyword arguments for the function.

### `run(steps, description)`

Run the steps of a pipeline script according to its command line. Command-line options: --list (show the steps), --only a,b (run these steps, whatever their environment), --from a (start at step a), --with openmc,mlip,network (also run steps that need these environments).

**Parameters.**
- steps: list of Step, in the order they run.
- description: text shown by --help (the pipeline script's docstring).

**Returns.** None.

```python
from filteratlas.common.pipeline import Step, run
run([Step("hello", lambda: print("hello"))], "demo")   # with no command-line options: prints == hello
```

## filteratlas.ingest.mp

Materials Project access: practical candidate set, structures, phonon DOS (bulk, via the public Delta table).

### `load_dos(path)`

Read a phonon DOS file (gzip-compressed JSON) as written by the pipeline. The dict has "frequencies" (THz), "densities", "projected_densities" (one row per site), "structure" (pymatgen Structure.as_dict()) and, for learned-potential files, "meta". Materials Project files are in data/upstream/mp/phonon_dos/<method>/<phonon id>.json.gz; SevenNet files in data/intermediate/mlip_atlas/.

**Parameters.**
- path: path of a .json.gz file.

**Returns.** dict as above.

```python
from filteratlas.ingest.mp import load_dos
dos = load_dos("data/upstream/mp/phonon_dos/pheasy/aaaegyio.json.gz")   # sapphire
```

## filteratlas.atlas.fronts

Pareto fronts of the atlas and the analyses built on them.

### `pareto(x, y)`

Pareto front of a set of points: the points not dominated on both axes (higher is better on both).

**Parameters.**
- x, y: values of the two figures of merit (array-like, same length).

**Returns.** boolean array, True for front members; of two identical points only the first is kept.

```python
from filteratlas.atlas.fronts import pareto
pareto([1, 2, 3], [3, 2, 1]), pareto([1, 2], [1, 2])
```

### `within(xhi, yhi, fx, fy)`

Points within one model uncertainty of a front: the +1 sigma point is not dominated by any front member.

**Parameters.**
- xhi, yhi: the two figures of merit evaluated at L0.8 * exp(+sigma) (numpy arrays or pandas Series).
- fx, fy: central values of the front members (iterables).

**Returns.** boolean array, one entry per point.

```python
import numpy as np; from filteratlas.atlas.fronts import within
within(np.array([1.5, 0.5]), np.array([1.5, 0.5]), [1.0], [1.0])
```
